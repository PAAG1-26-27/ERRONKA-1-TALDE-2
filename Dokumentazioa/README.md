# Dokumentazioa

Dokumentu nagusiak ez daude errepositorio honetan (fitxategi handiak edo bitarrak direlako). Talde-karpetan daude (`01_Erronka/00_Orokorra`):

| Dokumentua | Karpeta |
|---|---|
| Proposamena (PDF) | `10_Proposamena` |
| Memoria | `20_Memoria` |
| Aurkezpena | `30_Aurkezpena` |
| Irudiak (diagramak, logoa) | `10_Irudiak` |

Errepositorioan gordetzen direnak: iturburu-kodea (`Programazioa`), diagramen irudiak (`Diagramak`, `Datu_basea`) eta README hau.
